## Background

EvoCode 当前只有 Python 工程骨架，需要先建立终端交互入口，为后续 Core Runtime 提供用户界面。

## Goal

用户能够启动 EvoCode、查看启动信息、输入文本、使用基础命令并正常退出；本 Feature 不连接模型或执行工具。

## Target User

通过本地终端使用和开发 EvoCode 的开发者。

## Capabilities

- 用户可以通过命令行进入交互界面。
- 欢迎区显示 EvoCode 品牌、实际包版本、未配置的模型状态和当前工作目录。
- 用户可以提交单行输入，并在自然滚动的终端中继续交互。
- 普通文本得到模型尚未接入的英文提示。
- 用户可以查看帮助或通过退出命令结束交互。
- 用户可以在启动时查看帮助和版本而不进入交互。
- 空白输入被忽略，未知命令得到明确提示。
- 用户可以通过终端中断或输入结束信号正常退出，不出现异常堆栈。

## Non-functional Requirements

- 界面使用英文，结构简单且保持可维护。
- 窄终端与长路径不破坏信息可读性。
- 无颜色输出仍然可读；不修改用户终端主题。
- 用户输入和路径作为普通文本展示，不被解释为样式标记。
- 环境和依赖统一由 uv 管理，仅增加本 Feature 必需的依赖。

## High-level Design

CLI 负责启动参数、交互输入和命令分流；展示部分负责品牌与信息排版。使用自然滚动的单行交互，不采用全屏布局或固定底部输入区。

视觉以用户提供的设计图为主：像素感字符品牌和小型机器人、低饱和蓝灰、少量暖橙、Version / Model / Path 信息以及宽松的输入区留白。宽屏可并排展示字符图与信息，窄屏退化为紧凑品牌和纵向信息。背景沿用终端自身设置。参考图中的优化能力与模拟模型名称不属于功能范围。

版本来自包元数据，目录来自启动时的工作目录；普通文本本轮只给出未接入提示。未来可将文本交给 Agent Loop，本轮不引入模型接口或预留抽象框架。
